# AI 动画创作工作台：高保真前端原型设计

## 目标

构建一个原创的单页 Web 原型，面向动画、漫剧和短视频创作者。原型展示从剧本、资产到导演镜头的连贯生产流程，并以可替换的 Agent 服务边界为未来接入 Codex、ChatGPT、图像和视频 API 做准备。

本阶段不接入登录、云端数据库、真实模型 API 或视频渲染。所有项目数据保存在浏览器本地，所有 Agent 输出使用可见的模拟任务结果。

## 产品结构

应用使用固定左侧项目导航与右侧工作区。生产流程含三个一级页面：

1. **故事与剧本**：提供原文与镜头稿两个视图；原文可编辑，镜头稿按 Clip 与镜头显示。AI 操作可将剧情拆解为剪辑和镜头，并将识别出的角色、场景、道具加入待创建资产。
2. **设计与资产**：按角色、场景、道具筛选。列表呈现缩略图、状态与引用数；详情页可编辑名称、视觉描述、标签、提示词与参考图占位。资产被删除或重命名时，其镜头引用同步更新。
3. **导演工作室**：三栏界面。左栏为 Clip 列表，中栏为镜头卡片，右栏显示关联镜头组成的故事板。每张镜头卡均可编辑画面、景别、时长、声音和资产绑定。改变镜头或资产后，故事板即时更新。

全局顶部提供项目路径、保存状态与主题切换。暖象牙底色、深墨文字和烧橙强调色形成原创的电影制作台视觉语言。

## 共享数据与联动

页面使用一个共享的项目状态，包含 `script`、`clips`、`shots`、`assets` 与 `agentTasks`。

- 剧本拆镜生成 `clips` 和 `shots`，并生成可确认的待建资产。
- 资产页创建、编辑的资源保存在 `assets`，导演台的镜头选择器实时读取。
- 导演台更新画面、时长、景别或资产关系后，故事板卡片的标题、描述、视觉缩略图与统计立即刷新。
- 所有变更写入 localStorage；刷新页面后工作进度保留，并提供“恢复示例项目”入口。

## Agent 交互

右侧常驻或可展开的“创作副导演”面板含建议指令与自由输入。原型支持模拟：

- 从剧本生成分镜；
- 提炼缺失资产；
- 统一角色设定；
- 优化当前镜头提示词；
- 强化故事板的电影感。

每一次调用都进入一个短暂的处理中状态，并显示任务摘要。完成后通过明确的变更预览说明影响范围；在原型中可直接应用变更。未来 `agentService` 将替换为服务端任务 API：服务端持有模型密钥、调用 ChatGPT/Codex 或图像/视频供应商，并返回结构化补丁，前端仍按相同的预览与应用流程处理。

## 技术结构

- Vite + React + TypeScript；
- CSS 变量与原生 CSS 完成视觉系统，不依赖复制外站样式或资源；
- React Context 或轻量 store 管理项目状态；
- 模块划分为 `pages`（三页工作区）、`components`（导航、镜头卡、资产详情、故事板、Agent 面板）、`data`（示例项目）与 `services`（模拟 Agent / 后续 API 适配器）。

原型可通过 `npm run dev` 运行，并通过 `npm run build` 验证生产构建。

## 异常与验证

- 无选中资产或镜头时显示清晰的空状态；
- Agent 解析不到适合操作的内容时显示不可应用的结果，而非伪造修改；
- 删改资产时保留镜头中的“缺失资产”标识，避免静默丢失引用；
- 验证重点为页面导航、跨页数据同步、Agent 操作后的状态变化、刷新后数据恢复和生产构建通过。

## 非目标

本期不实现多人协作、账号与付费、音频配音、视频渲染队列、真实图像生成、复杂时间线、导出成片或第三方 API 密钥管理。这些模块在 UI 和服务层将保留扩展位置。
