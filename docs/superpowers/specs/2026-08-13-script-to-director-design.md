# 剧本到导演工作室自动串联设计

## 目标

当用户从原创或导入式路径确认锁定 1-1 剧本后，系统自动将同一份已锁定的分析结果转为可编辑的资产、剪辑、镜头和故事板。用户可在导演工作室请求重新分析镜头，并在预览后覆盖下游制作数据，不会改写锁定剧本。

## 范围与边界

- 两种剧本入口共用 `ScriptVersion` 与 `ScriptAnalysis`。
- 锁定会生成下游数据；同一版本可重复生成，但必须先预览再确认覆盖。
- 新版本剧本仍保留旧版本的下游数据；本次导演台默认展示当前锁定版本数据。
- 不接入视频、生图或 OpenAI API。本阶段分镜由本地确定性规则生成，后续可替换为 Agent/API 输出。

## 数据流

```text
原创剧本 / ChatGPT JSON 导入
             ↓
      ScriptAnalysis + 锁定版本
             ↓
  生成资产（角色 / 场景 / 道具）
             ↓
  生成剪辑（剧情段落）与镜头（画面、音频、时长、资产绑定）
             ↓
        导演工作室 + 实时故事板
```

## 生成规则

1. 每个 `characters` 条目生成一项“角色”资产；每个 `scenes` 条目生成一项“场景”资产；每个 `props` 条目生成一项“道具”资产。
2. 资产名称由分析文本中冒号前的名称取得；描述保留完整分析文本；各资产带上锁定版本 ID。
3. 生成一个或多个剪辑。首个剪辑使用分析摘要，镜头按场景、角色和道具依次组织，至少产生两条镜头。
4. 镜头绑定其涉及的场景、角色和道具资产，填入画面描述、基础音频、时长和景别；所有镜头带上锁定版本 ID。
5. 故事板继续从镜头实时派生，因此编辑镜头的标题、时长、资产绑定后会立即同步显示。

## 交互

- 在“确认并锁定剧本”后自动生成下游数据，并提示生成数量。
- 导演工作室顶部显示当前来源与版本，并新增“重新分析镜头”按钮。
- 点击重新分析只打开“分镜生成预览”，展示将生成的资产、剪辑和镜头数量；点击“确认覆盖”后才替换当前版本的下游数据。
- 若未锁定剧本，导演工作室不允许生成，并明确引导用户先完成剧本分析与锁定。

## 错误处理与验证

- 空分析数组仍可生成最小可编辑镜头，但避免无效资产引用。
- 测试须覆盖：锁定后生成版本绑定资产、镜头绑定资产、重新生成只替换当前版本的下游数据、手动编辑镜头仍可更新故事板数据来源。
- 完成后执行 Vitest 全量测试和生产构建。
