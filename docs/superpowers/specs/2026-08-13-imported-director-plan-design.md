# 导入式完整导演台 JSON 设计

## 目标

让用户在 ChatGPT Plus 内完成剧本润色、剧情场次、动作与分镜创作，再将完整 JSON 粘贴到“导入式剧本”。网站不再用本地规则二次拆解导入结果，而是校验、锁定并直接将用户的导演计划写入当前版本导演台和故事板。

## 用户流程

```text
原始剧情
  ↓
网页复制“完整导演台 JSON”提示词
  ↓
ChatGPT Plus 润色、拆场次、创作分镜
  ↓
用户粘贴 JSON 至导入式剧本
  ↓
网页校验 → 预览 → 确认锁定
  ↓
直接写入 Clip、镜头、动作、运镜、音频、资产绑定与故事板
```

导入提示词只要求 JSON，不允许 Markdown 代码块。它将包含当前原始剧情和严格结构；ChatGPT 要保留人物、事件因果与用户明确设定，不凭空更改核心事实。

## 导入 JSON 结构

```json
{
  "polishedScript": "润色后的正式剧本",
  "summary": "剧情摘要",
  "characters": ["林澈", "小狐"],
  "scenes": ["废弃城市街道"],
  "props": ["混合型浓缩炸弹"],
  "warnings": [],
  "clips": [
    {
      "name": "Clip 01",
      "summary": "废城探索",
      "shots": [
        {
          "title": "废城建立",
          "size": "远景 WS",
          "duration": 5,
          "visual": "……",
          "cameraMove": "缓慢推镜",
          "action": "林澈谨慎进入街道",
          "audioItems": [{"kind": "环境音", "content": "风声与机械低鸣"}],
          "assets": ["林澈", "废弃城市街道"]
        }
      ]
    }
  ]
}
```

## 校验与应用

- 必填：`polishedScript`、剧情摘要、三类资产数组及至少一个 Clip。
- 每个 Clip 必须包含名称、摘要和至少一个镜头；镜头需提供标题、景别、正时长、画面、运镜、动作和音频数组。
- 音频类型限定为环境音、对白、旁白、音效、音乐。
- 资产名称会生成或复用当前锁定版本的待完善资产卡；已有资产的视觉描述、参考图和历史不被覆盖。
- 资产绑定按名称解析；导入未知名称时建立待完善资产卡。
- 确认导入后仅覆盖当前版本 Clip/镜头/故事板来源，不修改原始剧情及其他版本。

## 编辑与回退

导入后的镜头直接出现在导演工作室中，并保留铅笔卡片内编辑器。用户可修改景别、画面、动作、运镜、音频和资产绑定；故事板实时同步。保留“AI 润色并生成导演台”作为本地规则备用入口，但导入数据不会被自动替换。

## 验证

- 测试提示词包含完整导演台 JSON 约定。
- 测试有效完整计划可解析为内部 Clip/Shot 数据，并保留动作、运镜、音频和资产名称。
- 测试缺少 Clip、镜头字段、非法音频类型或非正时长时出现中文错误。
- 测试将导入计划应用到项目时保留已有参考图元数据。
- 发布前运行 Vitest 和生产构建。
