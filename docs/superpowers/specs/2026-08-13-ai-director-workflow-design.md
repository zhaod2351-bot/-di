# AI 导演台润色、分镜与卡片内编辑设计

## 目标

把当前“抽取资产后生成固定两三条镜头”的导演台替换为完整 AI 导演工作流：AI 将原始剧情润色为正式剧本，按剧情节拍拆分场次/Clip，并为每场生成多条具有动作、运镜、音频和资产关联的镜头。故事板由镜头实时派生。用户可在每张镜头卡内点击铅笔展开高级编辑器，修改立即同步。

## 输入与覆盖规则

触发入口为导演工作室顶部的“AI 润色并生成导演台”。触发后直接覆盖当前锁定剧本版本的 Clip、镜头和故事板来源数据，不弹出确认步骤。

以下数据永不被此操作修改：

- 用户最初输入的原始剧情；
- 已锁定的剧本版本及其来源文本；
- 资产卡的名称、手动视觉描述、已上传参考图和参考图历史；
- 其他脚本版本的导演台数据。

覆盖后生成的 Clip、镜头、音频与资产绑定都是可编辑的；顶部继续保留“重新生成导演台”入口。

## AI 导演数据链

```text
原始剧情
  ↓
AI 润色正式剧本（保留人物、事件、因果，不凭空改变事实）
  ↓
剧情节拍 / 场次：建立、行动、反应、冲突、结果、转场
  ↓
Clip（每个节拍一段）
  ↓
每个 Clip 生成 3–6 条镜头
  ↓
右侧故事板实时读取镜头
```

每条镜头包括：景别、时长、画面描述、运镜、角色动作、对白/旁白/环境音/音效/音乐条目、场景/角色/道具资产 ID 绑定。

## 本阶段生成策略与后续 API 接口

本阶段不调用外部 API：使用可预测的本地导演规则，根据剧本事实和已锁定分析数据生成润色文本、节拍与分镜。生成服务的输入输出定义为结构化 `DirectorPlan`，以便后续将同一接口替换为 ChatGPT/Codex/API 的 JSON 结果，无需改 UI、资产或故事板。

## 卡片内高级编辑

镜头卡默认显示编号、景别、时长、画面摘要、音频摘要和关联资产。铅笔按钮切换当前卡片的展开状态，不打开独立弹窗，也不影响其他镜头。

展开编辑器包含：

- 景别下拉（远景、中景、近景、特写、俯拍、仰拍）；
- 时长输入；
- 画面描述、运镜、角色动作；
- 可添加、编辑、删除的音频条目，类型为环境音、对白、旁白、音效、音乐；
- 场景、角色、道具资产绑定，支持移除与添加；
- 仅在修改该镜头时更新故事板对应格。

## 故事板

故事板按当前 Clip 的镜头顺序渲染。每格展示景别、镜头标题、时长、画面摘要，以及关联资产/参考图可用时的视觉线索。镜头编辑后，无需单独保存或刷新，故事板即时同步。

## 验证

- 测试润色生成保留剧本人物/事件、输出多个 Clip、每 Clip 至少三条镜头，以及生成镜头含动作/运镜/音频。
- 测试重新生成只替换当前版本导演数据且保留资产参考图。
- 测试音频条目添加、删除和镜头编辑的不可变数据更新。
- 发布前运行 Vitest 全量测试与 Vite 生产构建。
