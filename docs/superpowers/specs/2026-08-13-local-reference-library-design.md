# 本地参考图资产库设计

## 目标

为角色、场景和道具资产提供与参考平台一致的参考图交互：鼠标悬停在资产主图上显示“上传/替换参考图”，点击后可选择或拖拽本地图片。图片保留在用户授权的 D 盘资产库，并在网页刷新后继续可见、可替换、可删除和可切换当前主图。

## 浏览器权限边界

网站不能自行写入 `D:\`。首次使用时，用户点击“设置本地资产库”，在系统目录选择窗口中选择或新建 `D:\SceneWeaver资产库` 并授予浏览器目录访问权限。浏览器会保存该目录句柄；若权限失效，界面要求再次授权。

不支持 File System Access API 的浏览器不隐藏上传功能：图片会降级保存在浏览器 IndexedDB，并显示“仅浏览器保存”的提示。

## 中文目录规则

默认根目录为用户选择的 `D:\SceneWeaver资产库`。每次上传生成如下中文路径：

```text
SceneWeaver资产库/
  余烬回声/
    全局资产/
      角色/
        林澈/
          参考图/
            2026-08-13_153015_正面设定.png
            2026-08-13_153122_战斗姿势.jpg
```

- 当前资产尚未绑定具体 Clip 时存入 `全局资产`。
- 已绑定镜头的资产优先写入对应 Clip，例如 `Clip 01/场景/废弃城市街道/参考图/`。
- 文件名保留原扩展名，前缀为上传时间；名称中的 Windows 非法字符会替换为下划线。
- 同名资产每次上传生成新文件，不覆盖旧文件。

## 数据模型

资产新增 `referenceImages` 数组，每项包括：

- `id`：稳定标识；
- `name`：实际文件名；
- `source`：`local-folder` 或 `browser-storage`；
- `previewUrl`：用于当前页面预览的对象 URL 或 Data URL；
- `createdAt`：上传时间；
- `isPrimary`：是否作为资产主图。

本地目录保存真实图片文件；项目状态只保存元数据，不保存 D 盘绝对路径。目录句柄独立存入 IndexedDB，避免将本地目录信息提交到 GitHub。

## 交互

1. 资产详情主图在悬停时覆盖半透明层，显示“上传参考图”或“替换主图”。
2. 点击后打开上传弹窗，支持拖拽和选择 PNG、JPG、WEBP，单文件上限 50MB。
3. 第一次上传会要求设置本地资产库；授权成功后写入中文目录并显示缩略图。
4. 多张参考图显示为历史列表。用户可“设为主图”“删除引用”；删除引用不会自动删除 D 盘原始文件，避免误删素材。
5. 资产主图展示当前主参考图；没有图片时维持现有渐变占位图。

## 错误处理与验证

- 拒绝非图片或超过 50MB 的文件，并显示中文错误提示。
- 未授权或权限过期时提示重新授权，不丢失当前项目数据。
- 测试覆盖中文路径生成、非法字符清理、唯一文件命名、主图切换、删除引用不删除真实文件的元数据行为。
- 发布前运行 Vitest 全量测试与 Vite 生产构建。
